# 🎓 Bem-vindo ao EduDocs

Este é um exemplo de documentação criada com **Docsify** para o seu projeto educacional.

## 🚀 Por que usar Docsify na Educação?

- **Rápido**: Ideal para manuais de laboratório ou guias de estudo.
- **Markdown**: Você já domina Markdown, então a curva de aprendizado é zero.
- **Acessível**: O site é leve e funciona bem em celulares de alunos.
